# Alice Windows 智能体桥接

## 当前状态

桥接代码已实现，但**没有安装、没有启动、没有创建计划任务**。启用前必须由操作者明确确认。

## 作用

- Alice 继续运行在 `192.168.72.157`。
- Luna 团队智能体继续运行在 Windows 本机。
- 本机仅向 Alice 发起出站请求；不创建 SSH 隧道、端口监听或可见终端循环。
- 同一成员同时最多执行 1 个任务；状态文件阻止重复执行。

## 启用前准备

1. 使用 Paperclip 官方接口为 7 个服务器智能体分别创建长期密钥。
2. 将示例配置复制到工作区外的私有目录并填入真实 ID。
3. 使用 `credential-helper.ps1 protect` 将凭据文件按当前 Windows 用户加密。
4. 先运行 `doctor.ps1 -Config <路径> -DryRun`；它只检查，不执行任务。
5. 明确确认后才运行 `install.ps1 -Config <路径>`。

## 停止与回滚

运行 `uninstall.ps1 -Config <路径>`。它只停止命令行与配置完全匹配的桥接进程，并只删除名为 `AliceWindowsAgentBridge` 的计划任务；不会删除 Alice、本地 Paperclip、配置、凭据或日志。

## 验收顺序

1. 只给一个测试智能体派发一张无副作用任务卡。
2. 确认任务只执行一次、无终端窗口、`health.json` 正常更新。
3. 立即测试卸载并确认进程停止。
4. 验收通过后再逐个启用其余成员。

## 故障处理

- 终端窗口出现：立即运行卸载脚本；不要重试安装。
- 重复执行：停止桥接，保留状态文件，检查任务 `updatedAt` 与租约记录。
- 身份不匹配：重新签发对应智能体密钥，禁止复用其他成员密钥。
- 本地 127 不可用：桥接不会执行任务；先恢复本地 Paperclip，再运行体检。
