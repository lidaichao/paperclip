# Alice Windows 智能体桥接

## 当前状态

桥接仍处于**禁用状态**：`main.ts` 与 `doctor.ps1` 会拒绝启动，未安装计划任务。配置采用 v3，运行号必须来自 192 的真实签领。独立缺陷 QA、失联收据恢复和真实本机运行验收未完成前不得安装。

## 作用

- Paperclip 协作控制面和测试部署位于 `192.168.72.157`；项目权威工程留在本机。
- Luna 团队智能体及其模型、工作区和凭据留在各自电脑。
- 本机仅向 Alice 发起出站请求；不创建 SSH 隧道、端口监听或可见终端循环。
- 同一成员同时最多执行 1 个任务；状态文件阻止重复执行。

## 启用前准备

1. 完成服务端签领、租约和写入围栏，并通过并发、断线、取消测试。
2. 为每名成员在自己的电脑保存独立配置与本人 Paperclip/GBrain 凭据；配置使用 `schemaVersion: 3`、192 `apiBase` 和 `localAdapterConfig`，不依赖 127 的 Agent 配置。
3. 用 `credential-helper.ps1 protect` 加密本人凭据，并验证 `/api/agents/me` 与 GBrain `whoami`。
4. 先只运行一次无副作用的本机前台试点；验证服务端真实 run ID、零可见终端、取消后进程停止和 192 无工程主仓。
5. 试点验收通过后，再逐人启用受控后台执行端。

## 停止与回滚

运行 `uninstall.ps1 -Config <路径>`。它只停止命令行与配置完全匹配的桥接进程，并只删除名为 `AliceWindowsAgentBridge` 的计划任务；不会删除 Alice、本地 Paperclip、配置、凭据或日志。

## 验收顺序

1. 只给一个测试智能体派发一张无副作用任务卡。
2. 确认任务只执行一次、无终端窗口、`health.json` 正常更新。
3. 立即测试卸载并确认进程停止。
4. 验收通过后再逐个启用其余成员。

## 故障处理

- 终端窗口出现：立即运行卸载脚本；不要重试安装。
- 重复执行：停止桥接，保留状态文件，检查任务 `updatedAt` 与租约记录。
- 身份不匹配：重新签发对应智能体密钥，禁止复用其他成员密钥。
- 192 不可用：执行端停止领取；已运行任务超过租约截止后停机，不允许离线继续写回。
